# EGBE: An Explainable Gradient Boosting Ensemble for Software Defect Prediction

Official replication repository for the research on **EGBE: An Explainable Gradient Boosting Ensemble for Software Defect Prediction**.

This project provides the implementation of an ensemble framework combining XGBoost, LightGBM, and CatBoost with dual explainable AI (SHAP and LIME) auditing for software defect prediction.

> **Note:** The paper is currently under review. Detailed documentation, benchmarks, and citation information will be updated upon publication.
